# 00 Project Overview

CarpCraft Intelligence is an Android-first commercial mobile application for carp angling. It helps anglers log private session evidence and turn that evidence into explainable, confidence-scored watercraft recommendations.

The product is not a catch predictor. It is an evidence-ranked assistant that helps with location, timing, presentation and baiting decisions.

## Core Value

- Private venue memory for swims, spots, sessions, catches and blanks.
- Structured session logging that treats blanks as learning data.
- Water temperature, dissolved oxygen, weather and observation capture.
- Deterministic rules first, with grounded AI/RAG later.
- Recommendations that always show confidence, evidence, data gaps and alternatives.

## Phase A Deliverables

- Repo scaffold and Windows-friendly scripts.
- FastAPI backend skeleton with route scaffolds.
- Flutter Android-first mobile shell.
- Deterministic rules engine and tests.
- Documentation, legal/compliance drafts and sample data.

## Non-Goals For Phase A

- Production authentication.
- Real PostgreSQL persistence.
- Live weather ingestion.
- Production AI calls.
- Play Store or App Store upload.
- Social sharing or public spot discovery.
