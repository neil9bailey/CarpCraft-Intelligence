# 13 Commercial Licensing

CarpCraft Intelligence is intended to become a commercial product. The app code uses a proprietary all-rights-reserved placeholder license in `LICENSE.md`.

## Rules

- Do not add MIT, Apache, GPL or another open-source project license to the app code.
- Track all third-party dependencies and their licenses.
- Review dependency license compatibility before commercial launch.
- Review contractor, contributor and assignment terms before accepting external code.
